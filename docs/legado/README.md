# Legado do projeto

Esta pasta guarda temporariamente os arquivos da versão anterior do Manual do NAO.

## Conteúdo

- `projeto-vite-antigo/`: aplicação original criada com Vite e React.
- `migration-vite-para-next.js`: script utilizado na primeira migração para Next.js.

## Situação atual

A aplicação oficial está na pasta `src/` da raiz e utiliza Next.js, React, Tailwind CSS e Framer Motion. Os arquivos desta pasta não são importados nem necessários para executar ou compilar o projeto atual.

O legado pode ser removido depois que o conteúdo migrado for revisado e aprovado.
